# Utility Suite

A free, open-source collection of browser-based utility tools. No accounts, no uploads, no server. Everything runs locally in your browser.

## Tools

| Tool | Purpose |
|---|---|
| Background Remover | AI background removal → transparent PNG (`@imgly/background-removal`) |
| Image Compressor | Reduce file size, quality control |
| Image Resizer | Exact dimensions or presets |
| Image Converter | PNG ↔ JPEG ↔ WebP |
| PDF Creator | Combine images into a PDF (jsPDF) |
| Instagram Grid Splitter | Slice into 3×3, 6×6, or 9×9 tiles |

**Your files never leave your device.**
